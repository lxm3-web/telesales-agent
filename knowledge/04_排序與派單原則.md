# 04 排序與派單原則

## 哪幾群該打（依主推商品）
看 `data/方案頁/` 的「主要對象」欄，對到族群；對不到的群明講「本週不打」及原因。

## 今天先打的 30 通，怎麼排（分數高的先）
| 條件 | 分 |
|---|---|
| 目前方案 ＝ 主推商品的前一階（例：主推紙本兩年，目前紙本一年） | +3 |
| 上次聯繫＝續訂 | +3 |
| 上次聯繫＝未接通 | +2（沒被拒絕過） |
| 婉拒理由＝沒時間 | +1（有需求只是忙，先傳 LINE） |
| 婉拒理由＝不需要／沒有要續訂 | −3（本週不打，列入下月） |
| LINE 好友＝是 | +1 |
| 續訂次數 ≥ 5 | +1 |
| 活動參與＝有 | +1 |

同分依訂閱年資高的先。每位電銷 10 通，三人共 30 通；LINE 好友「是」的分給同一人集中先傳訊。

## 不打的名單也要交代
分數 ≤ 0 的另列 `暫緩名單`，一句理由。
