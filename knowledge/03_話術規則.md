# 03 話術規則（每一版都照這個）

## 四步
1. 先同理：承接他的說法，不辯駁。
2. 重新定框：把「負擔」翻成「幫他解決問題的東西」。
3. 身份呼應：讓他覺得這是為他這種人準備的。
4. 利益聚焦：收在一個具體、對他有用的點，不收在價格。

【範例】客戶說「一週一本看不完」→「不是一定要看完的，但一定會把你這個身分需要關注的兩三個重點幫你 highlight，你只要抓住關鍵趨勢就好。」

## 贈品
開場不講；放在第 2 步之後、第 4 步之前；連著「對他有什麼用」一起講；一次只主打一樣。

## 語氣
像老朋友聊天；2 分專業 8 分白話；單句 ≤ 25 字；一次回應 ≤ 5 句；結語一針見血，不用「再考慮看看」。

## 每張話術卡的格式
```
▎族群名稱 ｜ 主推：方案名（價格、贈品，照方案頁）
〔一句話判讀〕
〔開場〕
〔主體〕（四步）
〔贈品切入〕
〔結語〕
〔他說「我沒時間」〕
〔他說「我不需要」〕
〔他說「我沒有要續訂」〕
```
